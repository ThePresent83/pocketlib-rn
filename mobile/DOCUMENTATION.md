# Документация проекта: PocketLib (React Native Edition)

## 1. Введение
**PocketLib** — это мобильное приложение для студентов и любителей чтения, предназначенное для организации личной электронной библиотеки. Приложение позволяет искать книги в открытых источниках, читать их онлайн или скачивать (офлайн), а также классифицировать литературу по учебным дисциплинам и курсам.

Проект разработан в рамках дипломной работы. Первоначальный прототип был создан на Python (KivyMD), однако для финальной версии был выбран фреймворк **React Native (Expo)**, что позволило достичь нативной производительности, плавности интерфейса и кроссплатформенности (Android и iOS).

---

## 2. Технологический стек

- **Фреймворк**: React Native (на базе архитектуры Expo).
- **Язык программирования**: TypeScript (обеспечивает строгую типизацию и защиту от ошибок во время выполнения).
- **Навигация**: Expo Router (современная файловая маршрутизация, аналогичная Next.js).
- **UI-библиотека**: React Native Paper (реализация принципов Material Design 3).
- **База данных**: SQLite (через модуль `expo-sqlite` для локального хранения данных).
- **Хранилище ключ-значение**: AsyncStorage (для сохранения прогресса чтения и настроек).
- **Внешние API**: Open Library API, Internet Archive, Project Gutenberg.

## 3. Архитектура приложения

Архитектура проекта построена по модульному принципу, разделяя логику (services), представление (app, components) и данные (db.ts).

│   │   ├── search.tsx    # Экран поиска книг через API

│   ├── book/

## 4. Структура базы данных (SQLite)

Локальная база данных `pocketlib.db` состоит из следующих таблиц:

1. **`disciplines`** (Дисциплины)
   - `id`: Первичный ключ
   - `name`: Название дисциплины (например, "Программирование")
   - `color`: HEX-код цвета для UI

2. **`courses`** (Учебные курсы)
   - `id`: Первичный ключ
   - `name`: Название курса
   - `year`: Номер курса (от 1 до 6)
   - `discipline_id`: Внешний ключ (ссылается на `disciplines`)

3. **`books`** (Книги)
   - `id`: Первичный ключ
   - `title`: Название
   - `author`: Автор
   - `description`: Аннотация
   - `cover_url`: Ссылка на обложку
   - `file_path`: Путь к локальному файлу (для скачанных/добавленных книг)
   - `is_downloaded`: Булево поле (доступность офлайн)
   - `ol_key`, `ia_id`, `gutenberg_id`: Идентификаторы во внешних библиотеках
   - `has_fulltext`: Наличие полного текста для онлайн-чтения
   - `discipline_id`, `course_id`: Внешние ключи (для фильтрации)

## 5. Взаимодействие с внешними API

Модуль `services/api.ts` отвечает за поиск и извлечение текстов.
Используется **Open Library Search API** (эндпоинт `/search.json`) для поиска по автору, названию или ISBN.

**Алгоритм получения текста книги:**
Приложение реализует "умный" поиск текста (Fall-back механизм), пытаясь загрузить его из разных источников:
1. Сначала проверяется наличие ID от **Project Gutenberg**. Текст загружается по прямой ссылке на `.txt` файл.
2. Если Гутенберга нет, приложение обращается к метаданным **Internet Archive** (`/metadata/{ia_id}/files`), ищет текстовые слои (`_djvu.txt`, `_full.txt`) и извлекает их через Range-запросы, чтобы экономить трафик устройства.

## 6. Модуль чтения (ReaderScreen)

Ридер (`app/reader/[id].tsx`) — это один из самых технически сложных компонентов:
- **Оптимизация рендеринга**: Текст книги программно разбивается на "страницы" по заданному лимиту символов (~1200 символов). Это позволяет избежать зависаний UI при рендеринге огромных текстовых блоков (например, книг на 500+ страниц).
- **Парсинг и очистка**: Загруженные из интернета тексты часто содержат системный мусор (теги, OCR артефакты). Функция `cleanText` удаляет нечитаемые строки с помощью регулярных выражений, оставляя только полезный текст.
- **Закладки и прогресс**: Прогресс (номер страницы и выбранный размер шрифта) сохраняется локально через `AsyncStorage`. При повторном открытии книги пользователь возвращается ровно туда, где закончил чтение.

## 7. Функционал приложения (Use Cases)

1. **Поиск и добавление**: Пользователь ищет книгу в глобальной базе, видит обложку и нажимает "+". Книга сохраняется в SQLite.
2. **Импорт PDF**: Пользователь на экране "Библиотека" нажимает на плавающую кнопку (FAB) и выбирает PDF-файл с телефона. Файл копируется в кэш приложения и добавляется в базу.
3. **Организация учебного процесса**: В "Настройках" пользователь создает "Дисциплину", привязывает к ней "Курсы". В карточке книги он назначает дисциплину, что позволяет легко фильтровать литературу к сессии.
4. **Чтение**: Приложение поддерживает как онлайн-чтение (скачивание текста "на лету"), так и офлайн (открытие ранее добавленных файлов).
